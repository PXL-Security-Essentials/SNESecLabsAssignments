# SecLabs Welcome

Welcome to the SecLabs platform and to your first SecLabs challenge. The goal of this first challenge is to help you get familiar with the platform and understand how it works.

In SecLabs, you will complete security labs and practical exercises in a hands-on environment. Once you have found the correct solution, you will discover one or more unique Flags. A flag is a unique code that serves as proof that you successfully completed the task. The flags in this environment are unique to each student and cannot be copied.

## Challenge
1. Click the **Start Container** button to start the virtual environment for this challenge.
2. The virtual environment will start a web server on **port 8080**.
3. After a few seconds, an IP address will appear. Copy the IP address and open it in a new browser tab using port **8080**: `http://x.x.x.x:8080`
4. You will be taken to a vulnerable website. Your goal is to find the **flag** within the environment.


**Hint**: Try logging in with commonly used default credentials for administrative platforms.
